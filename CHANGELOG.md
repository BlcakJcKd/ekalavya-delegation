# Changelog

All notable changes to Ekalavya will be documented here.

## Unreleased

## [0.4.0] - 2026-09-11

- Prepared the public open-source release with MIT licensing, provenance
  notices, repository hygiene checks, reproducible non-inference CI, and
  distributable package artifacts.
- Simplified user-level installation and onboarding with `eka setup`, including
  a staged interactive flow and an agent-safe, read-only setup report.
- Added factual live model discovery, explicit lifecycle and promotion controls,
  exact execution identity binding, and DeepSeek V4.1 Flash support while
  retaining historical and protected provider lifecycle states.
- Added local usage observability with task tags, safe token telemetry and
  coverage reporting, `eka usage`, `eka insights`, and categorical feedback.
- Improved truthful provider readiness so executable detection, configured
  state, authentication/readiness, and effective availability remain distinct.
- Added deterministic, explainable route recommendations that honour explicit
  user preferences and primary-native semantics, use comparable evidence only,
  and never execute or automatically delegate/fail over.
