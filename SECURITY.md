# Security policy

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting or a private security advisory
for this repository when that mechanism is available. Include the affected
version or commit, reproduction steps, impact, and a minimal proof of concept
when safe to share. We will acknowledge reports and coordinate any public
disclosure after a fix or mitigation is available.

If private vulnerability reporting is unavailable, contact the repository
maintainer through a private channel before sharing sensitive details. General
bugs and feature requests belong in the public issue templates.
